Quadro dos Sonhos é um aplicativo web inspirador projetado para ajudar as pessoas a criarem vision boards digitais (quadros de visão ou manifestação).
Com ele, você visualiza e manifesta seus objetivos para os próximos 1 ou 2 anos, adicionando imagens pessoais, frases motivacionais e organizando tudo em um mapa personalizado de sonhos.
Transforme pensamentos em realidade com uma experiência simples, bonita e motivadora! 🌙💫
Funcionalidades Principais

Cadastro e Login multilíngue (Português, Inglês e Espanhol)
Dream Map personalizado – crie seu quadro de sonhos com liberdade total
Upload ilimitado de fotos pessoais
20 imagens inspiradoras inclusas no plano
Frases motivacionais e bíblicas diárias
Acesso completo em todos os dispositivos (totalmente responsivo)
Assinatura acessível: apenas €4,99/mês

Design & Experiência Visual
O projeto segue uma identidade visual sonhadora e acolhedora, com uma paleta de cores suaves e harmoniosa:

Roxo suave (#a78bfa / #c084fc) → criatividade, espiritualidade e visão futura
Azul claro (#93c5fd) → confiança e serenidade
Toques de rosa → carinho e energia positiva
Gradientes delicados no fundo e nos elementos principais
Sombras leves e efeitos hover que transmitem movimento e esperança

Tudo pensado para inspirar calma, foco e motivação ao usar o app.
Tecnologias Utilizadas

Next.js (App Router) – performance otimizada e SEO-friendly
React – componentes reutilizáveis e estado local eficiente
TypeScript – maior segurança e manutenibilidade
Estilização inline avançada – controle preciso de cores, gradientes e animações sutis
Multilinguismo simples com useState – fácil de expandir para novos idiomas

Estrutura Atual do Projeto
Todas as telas de autenticação estão concentradas em duas páginas principais:

/cadastro → Página de registro com destaque nos benefícios do plano
/login → Página de entrada simples e direta, com link para recuperação de senha

Ambas compartilham o mesmo design consistente: fundo gradiente suave, card central branco com sombra roxa, títulos com gradiente de texto, inputs elegantes e botões com elevação ao hover.
Como Executar o Projeto Localmente

Clone o repositório:Bashgit clone https://github.com/seu-usuario/quadro-dos-sonhos.git
cd quadro-dos-sonhos
